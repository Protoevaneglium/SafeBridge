# Find Me in the separate 0.8 reconnect lab

Snapshots, on-device updates and remote sharing are distinct choices. **No HTTPS endpoint is configured and no public service is deployed.** Snapshots are usable source functionality; the default build cannot produce a working public live link. Neither path dispatches help.

Snapshots show coordinates, estimated accuracy, provider/device timestamp and elapsed age, with stale, approximate, cached and mock labels. Copy exports one snapshot; Share opens Android sharing for an app and recipient chosen by the user. Opening/selecting a sharing target does not prove sending or receipt. Other apps, clipboard/sync records and recipients may retain or forward copies.

## Optional configured live sender

The user chooses Until Stop or a future end date/time, enters a private one-use operator access code, reads the disclosure and grants optional foreground location/notification permissions. Recipients need no access code/account. Ticket distribution and operator eligibility are not supplied by this lab. Codes may themselves be exposed through device/clipboard monitoring.

A foreground location service creates an authenticated session before collecting estimates. Transient connection failures, rate limits and selected server errors keep consent/subscriptions/notification active with 1–60-second backoff. Only the newest previously unattempted fresh sample is sent; no route/history or stale backlog is replayed. Old-sample rejections wait for a new fix. Authorization, protocol, TLS, secure-storage or permanent failures stop locally rather than weakening trust. The service distinguishes consent running, server delivery acknowledged and connection unverified; none proves recipient receipt or the person's present safety.

Zero duration means Until Stop; positive chosen ends are immutable absolute UTC timestamps from the original device choice, sent unchanged across creation retries. The server does not shift them to the eventual creation time. Device/server clock disagreement may cause rejection or an end at a different real-world moment than the user intended; this lab does not provide a trusted clock-sync service. Local elapsed checks and server deadline checks are separate, and OS suspension may delay local execution. A 90-second data deadline erases the server point and marks the session paused, without ending consent. A fresh newer sample can resume that same ID/link. Confirmed Stop and expiry are terminal and cannot be revived. Android can still end the app without callbacks; Until Stop is an intent, not a continuity guarantee.

The server operator processes coordinates. Transport encryption is not end-to-end encryption. Independent writer/read/revocation capabilities and management receipts remain in a Keystore-encrypted, no-backup journal; only the read link is copied/shared. No coordinate history or recipient list is written by the app. Journal recovery never silently resumes collection; it restores only stopped/pending management for reconciliation/revocation.

Calculator and Close keep a running session separate from Stop. The pinned app Stop and foreground notification Stop invalidate local work and collection first, then attempt remote revocation using a separate coalesced worker. Offline uncertainty stays visible. Dispatched requests may arrive before authenticated server Stop; bytes and copies cannot be recalled. Until Stop has no automatic session deadline, and offline recipients can retain an old labeled position in tab memory. A signed management receipt can establish that a bounded-cache session is unavailable; that is not called a revocation acknowledgement. Confirmed remote end and failed local credential cleanup remain separate states.

## Recipient

A reachable HTTPS service and supported JavaScript browser are required, without installing Safe Bridge or opening an account. Position/Privacy pages display timestamp, estimated accuracy and increasing age. Connection loss or paused server data retains the last received point in tab memory, clearly marked last known/current unverified. It never invents movement or claims the sender is safe/stopped from an outage. Known positive expiry remains enforced locally using elapsed time, although browser suspension can delay execution. Confirmed Stop/expiry and manual Clear remove point/credentials from application state. Hidden tabs hide coordinates and stop polling; return requires revalidation. No persistence API is used for positions, but browser/OS memory erasure and exported copies are outside the app's control.

Optional “Open Google Maps” requires separate paged privacy disclosure and final confirmation for the chosen point. Google receives those coordinates and device/network information under its policies; the URL contains no session ID, generation or read capability. It is a selected snapshot, not a continuing live feed. No map tiles, geolocation prompt, remote fonts, analytics or third-party assets are loaded automatically. Street address is explicitly unavailable; no automatic geocoder is configured. This does not establish an affiliation with Google.

## Limits

Notification/system indicators, settings, browser/message/clipboard history and monitoring can reveal use. Location precision, network availability, lock/Doze/OEM behavior and Active apps Stop can interrupt the sender. No real Android, browser geometry, TalkBack, lock-screen, recipient-delivery or public-service test occurred.
